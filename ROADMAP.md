# 🗺️ IoT Platform Lab — Roadmap

This roadmap defines the learning path and practical milestones for mastering IoT protocols, cloud connectivity, backend architectures, and real-time monitoring.

---

## 📌 Phase 1: IoT Communication Protocols

- [ ] **MQTT Fundamentals** (Publish/Subscribe, Quality of Service 0/1/2, Retained Messages, Last Will & Testament)
- [ ] **HTTP / REST APIs** (HTTP Methods for IoT, JSON Data Payloads, Rate Limiting)
- [ ] **WebSockets** (Full-Duplex Real-Time Data Streaming for Dashboards)
- [ ] **CoAP & Lightweight Protocols** (Constrained Application Protocol basics)

---

## 📌 Phase 2: Embedded Device Integration

- [ ] **ESP32 MQTT Client** (Connecting microcontrollers to MQTT Brokers using Wi-Fi)
- [ ] **JSON Data Serialization** (Encoding & Decoding sensor measurements safely)
- [ ] **Reconnection & Resilience** (Handling Wi-Fi disconnects and broker failovers)

---

## 📌 Phase 3: Backend & Data Management

- [ ] **Node.js IoT Backend** (Express API + MQTT Subscriber)
- [ ] **Time-Series & Relational Storage** (PostgreSQL & InfluxDB for IoT telemetry)
- [ ] **Firebase Cloud Storage** (Realtime Database & Firestore integration)

---

## 📌 Phase 4: Real-Time Dashboards & Security

- [ ] **Web Dashboard** (HTML/JS + Chart.js / WebSockets for real-time visualization)
- [ ] **Security & TLS/SSL** (Encrypted MQTT via MQTTS, API Key Authentication, JWT)
- [ ] **Industrial IoT Protocols** (Modbus RTU / TCP, OPC UA basics)
